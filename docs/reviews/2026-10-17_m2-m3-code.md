## 실제 실행에서 먼저 드러난 사고

Git Bash `curl`로 연구를 맡기면서 한글 질문이 CP949 바이트로 전송됐다. 서버는 이를 대체 문자(U+FFFD)로 저장했고,
**소장은 깨진 질문을 읽을 수 없다고 말하지 않고 그럴듯한 질문을 지어내 연구를 진행시켰다.** 리서처 A는 그 질문으로 조사를 끝냈다.

대응:
- 서버: 본문을 UTF-8 엄격 디코딩(`TextDecoder fatal`), 문자열에 U+FFFD나 짝 없는 서로게이트가 있으면 400 (Codex 지적으로 두 번째 검사 추가)
- 소장: `brief.readable`/`unreadableReason` 필드. 읽을 수 없으면 추측하지 말고 멈추게 함. 모델 판단이라 최종 안전장치일 뿐이고, 1차 방어는 서버 검사
- 해당 연구는 멈춘 뒤 질문을 바로잡고 산출물·세션을 지워 처음부터 다시 돌렸다

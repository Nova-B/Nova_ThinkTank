## Codex 의견 요약

1. **아키텍처** — 직원 정의와 Study별 세션을 분리할 것. crew-office phase0의 MCP 서버는 가짜 답을 돌려줬으므로 실제 직원 간 협업은 미검증. 로그인이 없어도 localhost 바인딩·Origin 검사. 권한은 실행기·MCP에서 강제하고 저장은 앱이 맡을 것. 주장별 근거 구절·발행일·확인일·추론 여부 저장.
2. **오케스트레이션** — 단계 전환은 소장 제안 + 서버 검증. 상태와 재시도, 레드팀 이후 되돌아가기 경로. 동기 `ask_colleague`는 실행 슬롯 교착 → 비동기 큐, 같은 세션 동시 실행 금지. 엔진별 동시성·Study별 상한, 한도 소진 시 재시도 폭주 대신 대기. 세션 ID 즉시 저장, 체크포인트, 중복 방지 키, Windows 자식 프로세스 종료, 재시작 후 미완료 판정.
3. **Codex 0.163.0** — `--ignore-user-config` 후보. `--json`은 `item.*` 이벤트 위주라 `text_delta` 가정 금지, `--output-schema`로 구조화. `approval_mode`는 허용 도구에만. 엔진이 달라도 독립 판단은 보장 안 됨 → 원자료 먼저 평가.
4. **마일스톤** — M0 검증 확대, M1을 M1a(조사→반론→편집)/M1b(5단계)로 분리.
5. **결정 추천** — 2D Canvas, 초기 비공개 후 MIT, `보고서/` 하위에 날짜·Study ID, 가설 입력은 기본 + 건너뛰기 허용.
